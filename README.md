# Adam El Sakka, electrical engineering portfolio

Personal portfolio of Adam El Sakka, Electrical Energy and Control Engineering student at Université Grenoble Alpes.

A static site with no build step: open `index.html` in a browser, or host the folder as-is on GitHub Pages, Netlify or Cloudflare Pages.

## Pages
- **Home**: intro with an animated RC circuit, about me, and contact
- **Projects**: Rocket Science 101, SOLIDWORKS 3D CAD, MATLAB Onramp, physics and maths tutoring
- **Guides**: handwritten Math 282 calculus notes (34 pages, in-page reader), five MATLAB starter builds, and a physics formula sheet
- **Education**: study path (Université Grenoble Alpes, Beirut Arab University), certifications, languages and skills
