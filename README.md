# Adam El Sakka, electrical engineering portfolio

One-page portfolio of Adam El Sakka, Electrical Energy and Control Engineering student at Université Grenoble Alpes.

A static site with no build step: open `index.html` in a browser, or host it as-is on GitHub Pages, Netlify or Cloudflare Pages.

## Sections
- **Hero**: an interactive RC circuit with a live oscilloscope (flip the switch, change R and C)
- **Experience**: physics and maths tutoring, with a timeline chart
- **Education**: Beirut Arab University to Université Grenoble Alpes, as a scroll-drawn timeline
- **Certifications**: a draggable 3D ring of five credentials
- **Projects**: a classical physics book, in progress
