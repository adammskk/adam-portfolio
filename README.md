# Adam El Sakka, electrical engineering portfolio

One-page portfolio of Adam El Sakka, Electrical Energy and Control Engineering student at Université Grenoble Alpes.

A static site with no build step: open `index.html` in a browser, or host it as-is on GitHub Pages, Netlify or Cloudflare Pages.

## Sections
- **Hero**: an interactive Ohm's law lab: switch, DC/AC source, resistor and lamp, with a live oscilloscope
- **Experience**: physics and maths tutoring, with a timeline chart
- **Education**: Beirut Arab University, admissions (May 2026), Université Grenoble Alpes, as a scroll-drawn timeline
- **Certifications**: a draggable 3D ring of five credentials, showing my certificates (`certs/`), with a full-size view
- **Projects**: a classical physics book, in progress
- **Guides**: a guide library with an in-page reader: calculus (34 handwritten pages, 23 digital) and differential equations (27 handwritten pages, 21 digital)

`calculus/` and `differential-equations/` each hold the handwritten note pages (`pNN.jpg`) with thumbnails (`tNN.jpg`), and the digital edition in `digital/` (`dNN.jpg`, `tNN.jpg`).

## Privacy
The site makes no requests to third-party servers: fonts (Archivo and IBM Plex Mono, SIL Open Font License, see `fonts/`) are self-hosted. It sets no cookies and uses no analytics, tracking or session replay.
